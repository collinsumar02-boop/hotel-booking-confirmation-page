# Maison Soleil — Hotel Booking Confirmation

A responsive hotel booking confirmation page built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive layout with a collapsible mobile navigation menu
- Booking details, arrival information, Wi-Fi, and breakfast sections
- One-click Wi-Fi password copy
- Print-friendly booking confirmation

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Project files

- `index.html` — page structure and booking content
- `styles.css` — responsive layout and visual styles
- `script.js` — navigation, copy-to-clipboard, and print interactions
- `assets/` — images, icons, and locally hosted fonts

## Deployment

This is a static site and can be deployed directly from the repository with [Vercel](https://vercel.com/). No framework preset, build command, or output directory is needed.
